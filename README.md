# Vridhi AI Frontend

Frontend dashboard for **Vridhi AI**, an explainable credit-risk analytics platform for Indian MSMEs (HackConquest 2026, Problem Statement 12).

## Tech Stack
- **React 18** + **Vite**
- **Tailwind CSS**
- **Recharts**
- **Lucide React** (icons)

## Requirements
- Node.js (v18+)
- Backend running at `http://localhost:8000` (FastAPI)

## Setup & Running

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Environment Configuration:**
   Create `.env` from `.env.example`:
   ```bash
   VITE_API_URL=http://localhost:8000
   ```

3. **Start Development Server:**
   ```bash
   npm run dev
   ```

4. **Build Production Bundle:**
   ```bash
   npm run build
   ```
